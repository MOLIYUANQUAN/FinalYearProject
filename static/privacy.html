Friday — Privacy Policy

Last updated: 30 October 2026

Friday is a personal assistant built and used by one person, its owner (Zepeng Jia, University of Manchester final-year project). It is not offered to the public.

What Friday accesses

  • Google Calendar: to show the owner's schedule and add events he asks for.
  • Google Tasks: to list, add and complete his to-dos.
  • Gmail (if enabled): to search and read his mail, and to send mail only after he confirms each message.

How the data is used

Data from Google is used only to provide these features to the owner. It is not sold, shared with third parties, used for advertising, or used to train AI models. Requests are sent to OpenAI's API to generate replies; OpenAI does not use API data for training.

Friday's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where it is stored

OAuth tokens, conversations and Friday's notes are stored on the owner's own server (Fly.io, London). Nothing is kept beyond what Friday needs to work for him.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
