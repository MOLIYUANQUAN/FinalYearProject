## 一个周二

（示例，数据是编的）

**人在哪都能找到他。** 中午在图书馆，点开 iPhone 上的 Friday：「今晚有空吗？」同一段关系，同一份日历和待办——脑子在云上，电脑关机也能聊。

**开口就能聊。** 走路回宿舍，按住说话：「Lab 3 周四交。」它听完记下，回一句你听得见的「记下了」。

**需要时看一眼外面。** 晚上你问：「最近有什么值得看的大新闻？」它给两三条，每条带出处；没有来源就不装懂。

电脑上仍然快：Ctrl+Alt+F，今天已经在那儿；日历、Tasks、Gmail 真的能动。骨架是这些。贾维斯感来自：随时在、能开口、偶尔看得懂世界——不是功能清单勾满。

这段话里的体感，才是要做到的；不在路线里的，先不做。

## 四个「绝不」

只有一个 Friday，和你一段关系。对话就是界面，工具藏在后面。

1. **绝不说假话。** 日程、邮件、记忆、外面的新闻和行情，都只来自真实数据或工具结果；不知道就说不知道。看世界也绝不瞎编。
2. **绝不让你等。** 按下就在，开口就是答案，不给你列选项。
3. **绝不问你已经说过的事。** 说一次，它就记住；说错了，纠正一次就改对。
4. **绝不没经过你就动手。** 读可以直接读；发邮件、改日程、删东西，先问你一次。待办直接记下、划掉，页面给「撤销」。

做到这四条，靠一个原则：**能算的先算好，模型只照着说。** 时间、日子、几项、隔多久，都由服务端算好写进数据；开场那句话干脆整句由服务端写好。外面的世界同样：先查到，再说。

好看、利落、细节到位，是每一次提交的标准，不是一个阶段。

## 两个数字

- **每个工作日，你都主动打开它**（电脑或手机）。
- **它说错的次数：0。**

其余的数字都是工程目标，见下面的质量线。

## 已经有的骨架（保住）

- **快**：快捷键到窗口、开场卡片和那句话一起到。
- **真能动手**：Google 日历、Google Tasks、Gmail。
- **一个代理**：电脑和手机是同一段关系，不另做人。

待办第一刀已进 develop：一句话记下、到期回来、划掉、撤销。

## 路线

按 Jimmy 定的优先级往前走。每一步做完，先真用；没被用起来，就先修原因，不往下走。

### 1. 一按就在 · 做完了

电脑上 Ctrl+Alt+F：安排排好，那句话一起到；今天到下周日的日程本来就知道。10 月 16 日全量实测通过。

### 2. 人在哪都在 · 正路：云上 API + iPhone App

**做到：** 电脑关机也能聊；手机上是正式入口，不是临时隧道。  
以后若多人用：同一套服务按用户隔离，不绑某台 Windows。整条链路见 [cloud-and-iphone.md](cloud-and-iphone.md)。

按依赖拆三刀（做完一刀真用一刀）：

1. **云上部署** — FastAPI 常开；Google 授权迁到云域名；浏览器打开就能用。  
2. **登录** — 会话证明是你；电脑和手机共用。  
3. **iPhone App** — Capacitor 包现有界面，装到你的手机（TestFlight / Xcode）；不急着公开上架。

隧道方案（[phone-access.md](phone-access.md)）只作开发过渡，不当最终形态。

**演示时刻：** 电脑关机，用手机 App 说「提醒我下午续借书」，Tasks 里有；回家浏览器登录同一账号也在。

### 3. 开口就聊 · 手机稳了之后

**做到：** 能说、能听——先电脑，再和手机汇合。

第一刀：桌面按住说话、听回复；同一会话，不另做人。不是电影里永远在听的全双工贾维斯。

**演示时刻：** 走路时口述一件待办，它听懂并记下。

### 4. 看得懂外面 · 第三优先

**做到：** 新闻、行情、值得学的东西——有出处，能帮你读一层。

第一刀：只加带引用的只读工具；分析只基于工具结果；没有结果就说没有。X/推特以你能接上的来源为准。不做无人值守炒股或自动发帖。

**演示时刻：** 「最近有什么大新闻？」→ 两三条，每条带链接；或「这条值得学什么？」→ 基于原文的几点，不编细节。

### 5. 更像 Friday · 第四优先（收口，不是不做）

**做到：** 人味、干幽默——像伙伴，不像客服。

改说话方式（`VOICE`、开场语气），不靠堆新功能。排在手机、语音、看世界之后：先「在场」，再「像人」。

### 6. 替你做完 · 更后

说一句，事情办完，你只点一次确认：回邮件、改日程、记笔记、准备会面；确认卡片更清楚。

**演示时刻：** 「帮我回王老师说可以」：草稿、确认、发出。

### 7. 证明它 · 评测仍冻结

周二爱用过关后再解冻评测；合并 `main`、打 tag 之前先问 Jimmy。

## 先不做（别拿它们当进度）

- 开场白塞要紧邮件、周日晚看一整周、会前主动推要点  
- 课的截止日历订阅、学校邮件转发  
- 记忆的单独管理界面  
- 多智能体、「AI 员工」、花哨仪表盘、为炫技的浏览器托管  
- App Store **公开**上架与平台运营后台（先 TestFlight 给你自己；多用户隔离等第二个真人要用再做）  
- 为了幽默牺牲「绝不说假话」
