# Friday

> **Friday runs the background of your life.**  
> 交给 Friday，然后就可以忘了。

不是更好用的 ChatGPT。是**多了一个替你操心的人**——懂你、靠得住、事有人跟。主人不必管理管家；若每天还要打开它、喂它、再问「怎么样了」，那就只是另一个聊天机器人。

> **定位（滩头）：** 给**会写代码的早期创业者 / builder**用的个人管家——接上你的工具，替你盯开环、调工匠。  
> 先征服这类人（从 Zeep 自己开始），再谈世界。不做和大厂硬碰的「全能 Personal Agent」。

## GPT 和 Friday

| | GPT（顾问） | Friday（管家） |
| --- | --- | --- |
| 谁先开口 | 你带着问题去找它 | 它发现事情，再来找你 |
| 你是谁 | 总经理，临时叫顾问 | 主人；琐事不该由你记 |
| 聊完以后 | 回答结束，事就散了 | 没回的人、没关的环，它继续盯 |
| 价值 | 脑子好使 | **替你管掉本来要自己记、跟、判的事** |

你去找 GPT，通常是脑子里已经有了问题。  
Friday 应该是：「明天下午的会你还没准备——要我现在整理吗？」「John 两天没回，要跟进吗？草稿写好了。」

## 能力模型：调工具，不当全能工匠

Friday **不必自身多强大**。她的价值是：知道你要什么 → 挑对工具 → 确认后替你开跑 → 把结果收回来让你拍板。

| | 错误方向 | 正确方向 |
| --- | --- | --- |
| 肌肉在哪 | Friday 自己会写代码、会搜全世界 | Cursor、日历、邮件等**已经更强的工具**在干活 |
| 她是谁 | 第二个 IDE / 第二个搜索引擎 | 会调工匠的管家 |
| 加能力时 | 「再给她塞一个大模型技能」 | 「接上你已经在用、比她自己写更强的东西」 |

样板（已跑通）：抱怨不好用 → `note_friction` → 确认后 Cursor Cloud Agent 改仓库 → 对话里看文件列表/说明 → 确认后合并 `develop` 并部署。  
人设记一句：**管家不是全能工匠，是会调工匠的人。**

## 谁先服务（滩头用户）

Zeep（英文名；正式名 Zepeng Jia）本人是**学生 + 程序员 + 创业者**的综合体——一条人生里同时扛三件事，不是三个独立 Persona。  
Friday **只做一条关系**，覆盖他一天里切换的角色；不拆 Student Agent / Dev Agent / Founder Agent。

| 侧面 | 带来什么 | 产品含义 |
| --- | --- | --- |
| 学生 | 课表、截止、会——开环密度高 | 日历 / Tasks 要真、打扰要准 |
| 程序员 | 改产品、审改动、部署 | Cursor → 预览 → 确认上线 |
| 创业者 | 判断、优先级、少自己当秘书 | judgement；付费意愿主要在这里 |

**付费能力：** 创业者（尤其有收入/融资、把时间当钱）> 职业程序员 > 纯学生。  
滩头认的是 **builder / 早期 founder（会写代码）**；可以仍是学生身份，但买单理由是「把产品和日子跑起来」，不是「写作业助手」。

**征服顺序：** Zeep 自己用到离不开（周二测试）→ 少量像他的 builder（同一套 Action）→ 再想分发与更多人群。

**先不认：** 纯学生市场、非技术创始人、大众「全能个人代理」。

## 护城河：Action，不是 Context，也不是分发

Personal Agent 常被拆成三块：**Context / Action / Distribution**。

| | 大厂 | Friday |
| --- | --- | --- |
| Context（记忆、档案） | 容易抄；一份 memory 文档可以迁走 | **不当护城河**；可迁、当燃料 |
| Distribution（系统入口、导流） | 烧钱、亏钱导流到赚钱业务也行 | **别比** |
| Action（接进生活与工程的连接） | 广而浅 | **深而窄：他真在用的那几条链** |

真正难搬的是已经接上的 Action：Cursor ↔ Friday ↔ 确认部署、Google 日历 / Tasks / Gmail、手机与云上同一段关系。  
迁移走 = 重接 OAuth、钥匙、确认边界与习惯——这才费精力。

**怎么打仗：** 不硬碰硬做全能代理；不大比拼模型和分发。  
用滩头用户的真实需求把 Action 图织密——先让 Zeep（及像他的 builder）离不开，再谈复制。

加能力时多问一句：**这是不是加深了一条难迁移的 Action？** 只堆 Context 或只做热闹分发 → 多半不是核心。

## 管家的工作循环

```text
Observe → Understand → Manage → Ask → Act → Follow up
```

观察数字生活 → 理解发生了什么 → 维护没关上的事 → 需要你判断时才问 → 权限内该做的就做 → **做完继续追踪**。

最难的不是「能不能发现事情」，而是 **judgement：什么值得打扰你**。一天问 25 次，三天就卸载。好管家知道：自己处理 / 等一等 / 轻轻提醒 / 必须马上找你。

聊天还在，但不是唯一界面。打开时更像：

> **需要你**（只要真正重要的几件）

其余在背景里管。没有就不出声。

## 做功能时只问一句

**这是不是减少了 Zeep 必须亲自管理的一件事？**

否 → 多半不是核心。酷不酷不进决策。

第二问（能力从哪来）：**这件事是不是该交给更强的外部工具，而不是让 Friday 自己硬扛？**  
是 → 接工具 + 确认边界；否 → 才考虑她本地薄能力。

长期 KPI 不是每日聊天次数，而是：**替用户关上了多少 open loops**。

## 主战场：网页（电脑 + 云上同一张脸）

Zeep 开发机是 **Windows**，独立 iPhone 包暂时不做。  
**产品面 = 本机窗口（Ctrl+Alt+F）+ 云上网页（`friday-jimmy.fly.dev`）**，同一套 UI / API。  
Safari「添加到主屏幕」可作手机过渡入口；原生壳等有 Mac 再说，**不阻塞进度**。

## 四个「绝不」

只有一个 Friday，和你一段关系。对话是入口之一，工具藏在后面。

1. **绝不说假话。** 日程、邮件、记忆、外面的事实，都只来自真实数据或工具；不知道就说不知道。
2. **绝不让你等。** 按下就在，开口就是答案，不给你列选项。
3. **绝不问你已经说过的事。** 说一次就记住；说错了，纠正一次就改对。
4. **绝不没经过你就动手。** 读可以直接读；发邮件、改日程先问一次。待办可直接记下并给「撤销」。主动操心时：该你决定的才问，不问假热闹。

原则：**能算的先算好，模型只照着说。**

## 两个数字（现阶段）

- **每个工作日，你都主动打开它**（电脑网页或云上）——先证明「在」和「真」。
- **它说错的次数：0。**

管家循环做起来后，再看「它来找你的那些次里，有几次你觉得值」。

## 已经有的骨架（保住）

- **快**：快捷键到窗口、开场卡片和那句话一起到。
- **真能动手**：Google 日历、Google Tasks、Gmail。
- **一个代理**：本机和云上是同一段关系。
- **云上大脑**：Fly.io（`friday-jimmy`）常开。
- **脸**：黑白、白环；桌面 `friday-ring.ico`。
- **待办**：一句话记下、到期、划掉、撤销。

## 路线（网页优先；管家提前）

目的地是 Observe→Follow up。  
撒谎的管家比懒的更糟——所以先保证数据真、入口稳，然后**立刻**做管家薄刀，不再绕路去「看新闻 / 全语音」。

### 刀 0 · 一按就在 · 做完了

Ctrl+Alt+F：安排排好，那句话一起到。

### 刀 1 · 网页就是产品 · 正在做

**做到：** 打开就是 Friday，不是工具站。登录一次记住；本机和云上同一张脸。

- 云上 + 会话 Cookie · 已通  
- 打磨网页：登录顺、卡片真、待办能动、手机浏览器也能用（主屏幕可选）  
- **不做：** 等 Capacitor / Expo / Mac 才继续

### 刀 2 · 管家第一刀 · 网页上立刻做（目的地的第一截）

全部服务端从已有数据算出，**不经过模型瞎编**；没有就不显示。

1. **需要你** — 打开时最多几条：过期 / 今天截止且未过点的待办、几小时内要开始的会；**明天的事只在日程分区，不进「需要你」。**  
2. **盯住没关上的环** — 下一截：你发出去、N 天没回的邮件，问要不要跟进（可带草稿）。  
3. **你点一下才动** — 改期、回复、划掉；确认边界不变。  
4. **记下不好用 → Cursor 改 → 确认部署** — 抱怨 → `note_friction`；开着的摩擦每轮注入。你说修 → 确认 → `fix_friction_with_cursor`（Cloud Agents REST；本机/云上分支或 PR）→ `pending_ship` 展示改动 → 确认 → `ship_pending_fix`（合 `develop` + `deploy_fly`）。需要 `CURSOR_API_KEY`；云上合并可能还要 `GITHUB_TOKEN`。这是「调工匠」的样板，不是让她自己当 IDE。

**验收：** 你没先问它——打开网页就看到「需要你」里的真事；点一下能办完或记下下一步；骂过的点她不再犯同样的错；摩擦→Cursor→预览→部署能闭环。

### 刀 3 · 用一周真生活验收 · 门禁

周二你会不会自己打开？它指出的事有没有用？说错了没有？  
不过关：修判断、修数据，不上语音花活。

### 刀 4 · 开口就聊 · 网页第一刀已接上

点「说」→ 说完再点「完」→ Whisper 转写 → 走同一套对话 → 把回复念出来。  
用来口述待办、问日程、跟进——不是永远在听的全双工贾维斯。

像人说话的三件事：开口问的那轮回答写成口语（一到三句、不列清单、时间说「下午三点半」）；
一句写完就念、不等整段；白环跟着真实响度起伏，点一下就停。  
有 `ELEVENLABS_API_KEY` 时用 ElevenLabs（`eleven_v4` + 自选 Voice ID），中英都更自然；
没有就退回 OpenAI `marin`。听写仍是 Whisper。

### 刀 5 · 外面的世界（只服务你的松线）

不是「最近大新闻」。是：跟你正在管的事有关的外界变化（例如你在盯的截止日期相关通知）。没有来源就不说。

### 收口 · 更像 Friday

**气质钉死：** 名字用 Friday，味道借电影 JARVIS——中文、利落、偶有干幽默；别学 MCU Friday 冷到没情绪，也别学客服热情。声音可后调；先改 `VOICE` / `SPOKEN`（2026-10-19 已开第一刀）。

## 先不做（别拿它们当进度）

- 一天几十次推送、假热闹的「主动」  
- 为仪表盘而仪表盘、开场塞满邮件  
- 通用新闻阅读器、无人值守炒股 / 发帖  
- 记忆管理后台、多智能体、「AI 员工」  
- 把 Friday 做成第二个 IDE / 全能工匠（该接 Cursor 等工具时别自己硬扛）  
- 和大厂比 Context 壁垒或分发烧钱；做「服务所有人的全能 Personal Agent」  
- 先冲纯学生市场或非技术大众（滩头之外）  
- App Store 公开上架、Expo Go 套壳当产品  
- 等 Mac / 原生壳才推进管家
