# Personal Agent — 产品北星

> 你的个人代理：一个认识你、盯着你的生活碎片、带主见回应你的单一智能体。

不是导师会面工具、不是课表查询器、不是邮件客户端、不是 FYP Demo 壳。  
今日安排 / 邮件 / 记忆 / 重要对话 = **证明时刻**，用来检验品类，不是产品定义。

## 设计戒律

1. **One** — 一个 Agent，一段关系  
2. **Know me** — 不知道你是谁就不算 Personal  
3. **Decide** — 先结论，有主见  
4. **True** — 不编造人生数据  
5. **Quiet** — 对话即界面；工具隐形  
6. **Earn action** — 读自动，写/发确认一次  
7. **Tuesday test** — 普通周二愿不愿意打开？不愿意 = 未完成  

## 爱用门禁（先于评测）

连续一个普通周期主动打开，且：关系成立、少当自己的秘书、品味利落、零幻觉。  

**在 Tuesday test 通过前：不扩写评测任务、不合 `main`、不打新 milestone tag。**  
现有 [evaluation/](evaluation/) 证据冻结，报告需要时再摘。

## 每天怎么开

```bash
# Windows（仓库根目录）
.\scripts\start.ps1

# 或
.\.venv\Scripts\python.exe -m src.main
```

打开 [http://127.0.0.1:8765](http://127.0.0.1:8765) — 应直接看到「认识你」的个人态势，而不是 Demo 按钮墙。
