# Personal Agent — 产品北星

> 你的个人代理：一个认识你、盯着你的生活碎片、带主见回应你的单一智能体。

不是导师会面工具、不是课表查询器、不是邮件客户端、不是 FYP Demo 壳。  
今日安排 / 邮件 / 记忆 / 重要对话 = **证明时刻**，用来检验品类，不是产品定义。

## 设计戒律

1. **One** — 一个 Agent，一段关系  
2. **Know me** — 不知道你是谁就不算 Personal  
3. **Decide** — 先结论，有主见  
4. **True** — 不编造人生数据  
5. **Quiet** — 对话即界面；工具隐形  
6. **Earn action** — 读自动，写/发确认一次  
7. **Tuesday test** — 普通周二愿不愿意打开？不愿意 = 未完成  

## 体验的四个时刻

1. **打开** — 按 Ctrl+Alt+F，它先开口：此刻最该知道的事。日历由服务端直接读，回答边想边出字。  
2. **问** — 它本来就认识你：此刻时间、档案、记得的事每一轮都在上下文里，不靠模型「想起来去查」。  
3. **说一次** — 顺口提到的长期事实它会记下；纠正一次就改对。记忆只存在本机（`data/memory/facts.json` 不进 Git）。  
4. **做事** — 写/发确认一次；只有它真在等确认时，「好的」才算同意。  

刷新页面不丢对话；同一天两小时内回来算同一次会话，否则重新开场。

## 每天怎么开

装一次：`.\.venv\Scripts\python.exe scripts\install_shortcuts.py`（桌面 + 开始菜单 + 开机常驻；`--remove` 全部撤掉）。  
之后按 Ctrl+Alt+F：Friday 出现；它在最前面时再按一次就收起。常驻进程自己监听快捷键，服务和日历一直是热的；代码变了才换新进程。  
也可以点桌面上的 Friday 或双击 `Friday.cmd`。强制重启：`open_agent.py --restart`；停掉：`--stop`。服务日志在 `data/logs/`。

## 门禁怎么看

```powershell
.\.venv\Scripts\python.exe scripts\usage_report.py
```

最近 7 天每天打开几次、聊了几条、等第一个字多久、出错几次。只记元数据、不记对话内容，数据在本机 `data/usage/`。

## 爱用门禁（先于评测）

连续一个普通周期主动打开，且：关系成立、少当自己的秘书、品味利落、零幻觉。  

**在 Tuesday test 通过前：不扩写评测任务、不合 `main`、不打新 milestone tag。**  
现有 [evaluation/](evaluation/) 证据冻结，报告需要时再摘。
